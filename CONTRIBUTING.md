# Contributing to Bref

Join [Discord](https://discord.gg/JpgQRTUsVS) to ask questions, share ideas and discuss Bref.
Help shape the project by filing [GitHub issues](https://github.com/feuersteiner/bref-ui/issues), checking for existing reports first and keeping each issue focused on one topic.
For bugs, include a minimal reproduction, steps to reproduce, expected and actual behavior, and relevant package versions and browser details.
For feature requests, explain the problem, the use case and any workarounds already tried.
Pull requests are not accepted; feedback through issues and Discord helps guide what gets built.
