# Bref-ui docs

`src/routes/(docs)/` groups routes; `(docs)` is absent from public URLs.

- `/`: home; `/button`, `/tabs`, etc.: component documentation.
- `/library`, `/cli`, `/themes`: package usage, copying components and theme guides.
- `/demo` and `/demo/themes/[theme]`: catalog and palette previews in the docs shell.
- `/demo/todo`, `/demo/house-shop`, `/demo/runner-ai`: standalone demos without the docs shell.
